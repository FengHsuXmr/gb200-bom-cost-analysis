# GB200 NVL72 AI 伺服器機櫃 BOM 與成本分析

以產品 PM／成本工程的角度，拆解 NVIDIA GB200 NVL72 機櫃（72 顆 B200 GPU、36 顆 Grace CPU）的物料清單（BOM），
建立可調整的成本模型，並做敏感度分析、蒙地卡羅模擬、降本方案評估、晶片 should-cost 與客戶端 TCO。

> 所有單價為依公開研調與媒體報導推估的**模型值**，不是任何公司的實際報價。每個料號的依據寫在 `data/bom_gb200_nvl72.csv` 的 `source_note` 欄位。

## 主要結論（base case，整櫃售價 300 萬美元）

| 指標 | 數值 |
|---|---|
| 整櫃 BOM 成本 | **$2.82M**（low $2.46M／high $3.41M） |
| ODM 毛利／毛利率 | $178K／**5.9%** |
| 運算晶片（GB200 Superchip + 網卡 + DPU）占成本 | 81% |
| 非 NVIDIA 料件（成本工程可著力的範圍） | $368K（約 13%） |
| 蒙地卡羅毛利率 P10／P50／P90 | -2.1%／3.7%／8.1% |
| 7 項降本方案合計 | 每櫃省 $70K，毛利率 5.9% → 8.3% |
| B200 晶片 should-cost | 約 $6,400（HBM 占 45%） |
| 客戶端 TCO（5 年折舊、利用率 80%） | 約 $1.94／GPU-hr |

1. **成本高度集中**：GB200 Superchip 一項就占整櫃成本 77%；它的單價每變動 1 萬美元，整櫃成本就變動 36 萬美元，幾乎等於全部非 NVIDIA 料件的總和。
2. **ODM 的風險在晶片採購模式**：若 ODM 自行買斷晶片再轉賣，晶片價格波動會讓毛利率在負值到 8% 之間擺盪；改採 NVIDIA 代購（consign／pass-through）可把風險移出 ODM 損益表。
3. **非 NVIDIA 料件才是降本主戰場**：非 NVIDIA 料件（液冷、電源、機構、線材、測試等）合計約 $37 萬，透過規格調整（CDU、SSD）與雙供應商議價，可提升約 2.3 個百分點毛利率。
4. **HBM 是晶片成本最大變數**：HBM3E 每 GB 從 15 美元漲到 24 美元，B200 成本增加約 27%。

## 專案結構

```
gb200-bom-cost-analysis/
├── data/
│   ├── bom_gb200_nvl72.csv     # 21 個料號：數量、low/base/high 單價、供應商、台廠、來源
│   └── b200_should_cost.csv    # B200 晶片成本拆解
├── src/
│   ├── model.py                # 成本模型、敏感度、蒙地卡羅、降本方案、TCO
│   └── run_analysis.py         # 一鍵產生全部圖表與結果
├── outputs/
│   ├── charts/                 # 6 張分析圖
│   ├── results.json            # 主要數值
│   └── *.csv                   # 子系統、Pareto、敏感度、降本、HBM 結果表
└── tests/test_model.py         # 8 項單元測試（資料一致性與與公開估計的合理性）
```

## 使用方式

```bash
pip install -r requirements.txt
python -m src.run_analysis               # 產生 outputs/
python -m src.run_analysis --asp 3200000 # 改整櫃售價重算
python -m pytest -q                      # 執行測試
```

要更新單價，只要改 `data/bom_gb200_nvl72.csv` 再重跑即可；要新增降本方案，在 `model.py` 的 `DEFAULT_LEVERS` 加一筆。

## 分析方法

| 分析 | 做法 | 對應的 PM／成本工程問題 |
|---|---|---|
| 子系統拆解、Pareto | 依料號加總，按子系統與供應商類型分群 | 錢花在哪？誰拿走價值？ |
| 敏感度（Tornado） | 一次只把一個料號調到 low／high | 哪些料號最需要盯價格？ |
| 蒙地卡羅 | 每個單價以三角分佈抽樣 20,000 次 | 報價時毛利率的風險區間有多大？ |
| 降本方案 | 規格／商務／製程／設計四類，量化省多少、毛利率提升幾個百分點 | 下一季降本專案先做哪幾項？ |
| Should-cost | B200 晶粒、HBM、CoWoS 封裝、其他元件 | 跟供應商談判的成本底線在哪？ |
| TCO | 直線折舊 + 託管（含電力）÷ 利用的 GPU 小時 | 客戶買這櫃，每 GPU 小時成本多少？ |

## 限制

- 單價為推估值，實際價格依客戶、量級、合約而異。
- 未包含叢集層級的 InfiniBand／乙太網路交換器與光模組，也未包含機房建置成本。
- ODM 毛利率以「ODM 買斷全部料件」計算；實務上晶片常由 NVIDIA 代購，帳面毛利率會較高。
